# 🎮 XO Battle – Tic Tac Toe Game

A fun and interactive **XO (Tic Tac Toe) game** built with Flutter. Challenge yourself, make smart moves, and try to get three X's or O's in a row to win!

## ✨ Features

- 🎯 Interactive Tic Tac Toe gameplay
- ❌ X and ⭕ O player turns
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 🔄 Restart and play again
- 📱 Responsive Flutter interface
- 🎨 Clean and user-friendly design

## 🚀 Getting Started

Follow these steps to run XO Battle locally.

### 1. Clone the Repository

```bash
git clone https://github.com/AhmedRaza2007/xo-battle.git
```

### 2. Navigate to the Project

```bash
cd xo-battle
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Run the Application

```bash
flutter run
```

## 🧪 Run Tests

To execute the project's automated tests:

```bash
flutter test
```

## 🎮 How to Play

1. Start a new game.
2. Two players take turns selecting empty cells.
3. Player X and Player O alternate their moves.
4. Get three matching symbols horizontally, vertically, or diagonally to win.
5. If all cells are filled without a winner, the game ends in a draw.
6. Restart the game and play again!
